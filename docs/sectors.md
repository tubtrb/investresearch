# 2차 업황·섹터 리서치

10개 섹터를 항상 출력합니다. 반도체는 HBM·서버 DDR5 DRAM·기업용 SSD를 각각 판정하므로 **총 12개 행**입니다. 바이오·헬스케어의 첫 범위는 바이오 CDMO, 전력기기는 변압기, 방산은 지상방산입니다. 해당 제품군 결과를 더 넓은 산업 전체로 외삽하지 않습니다.

| 섹터 | 수요 | 두 번째 확인선 | 참고만 하는 자료 |
|---|---|---|---|
| 반도체 (3개 제품군) | 제품별 주문 물량 | 같은 규격의 계약가 | 출시·출하·전사 LTA, 현물가, 전망, 업종 상대수익률 |
| 자동차·부품 | 신차 판매 대수 | 판매가 대비 인센티브 비율의 변화 | 평균 판매가, 수출액, 현대차 등 개별 업체 |
| 조선 | 확정 수주 CGT | 같은 선종·사양 신조선가 | 잔고, 다양한 선종이 섞인 신조선가 지수 |
| 전력기기 | 취소 차감 변압기 수주액 | 같은 규격의 계약단가 | 전체 수주잔고, 납기(수요와 생산 제약을 함께 반영) |
| 방산 | 확정 신규 계약액 | 계획 대비 정시 인도율 | 수주잔고, 양해각서·선정·납기 조정 |
| 2차전지 | 같은 업체군의 EV 배터리 출하 GWh | 같은 EV 생산라인 가동률 | 글로벌 차량 탑재량, ESS 출하, 한 업체 생산 개선 |
| 화장품 | 한국산 화장품 수출액 | 동일 상품·시장 유통 재주문 물량 | 통관 잠정치, 소비자 검색·유통 입점 |
| 바이오·헬스케어 | 확정 신규 바이오 CDMO 수주액 | 동일 CDMO 라인 가동률 | 의약품 수출·매출, 신약 임상, 계약 총 누계 |
| 게임 | 동일 타이틀 순판매 수량 | 같은 정의의 신규 유입 30일 유지율 | IP 매출, 동시접속자·리뷰, 출시 예정 |
| 엔터 | 유료 공연 관객 수 | 동일 범위·통화의 실질 티켓 단가 | 공연 매출·굿즈·투어 발표 |

## 실행과 점수

```sh
python -m research.sectors --input examples/sectors.json --format markdown
python -m research.sectors --input examples/sectors.json
python -m unittest discover -s tests -v
```

`observed`인 두 값이 같은 프로필·기간·비교방식·측정 범위에 있을 때만 방향을 판정합니다. 두 값 개선은 `pass`, 두 값 악화는 `fail`, 혼조·보합은 `hold`. 인센티브 비율은 상승이 불리해 부호를 반대로 판정합니다. 그 외에는 `unknown`으로 보류하며 투자 매력이 없다는 뜻이 아닙니다. 전망·가격 추정·잠정치·매출/출하 대용치는 맥락에 남지만 자동 판정에 입력하지 않습니다. 단일 기업 관측은 해당 기업 범위를 벗어나 집계하지 않습니다. 선종별 가격의 변경, 컨콜 정성 표현, 리뷰 등으로 없던 숫자를 대체하지 않습니다.

## 입력

독립 CLI는 `cutoff`, 관측 행 배열 `observations`, 선택적인 프로필별 `scopes` 맵을 받습니다. 행마다 `profile`, `metric`, `period`, `scope`, `available_at`(시간대 포함), `source`, `grade`, 한 줄 `note`가 필요합니다. 정량 축은 `value`, `unit`(% 또는 %p), `comparison`까지 받습니다. 기준은 [PROFILES](../research/sectors.py) 참조. 월간은 YYYY-MM, 전년 동월 대비; 분기는 YYYY-Qn, 반도체는 전분기 대비, 나머지는 전년 동분기 대비입니다. 기간이 끝나지 않은 숫자는 전망으로만 넣습니다. 같은 프로필에서 범위가 여러 개면 관찰 범위를 명시하기 전까지 추론하거나 합산하지 않습니다. 가장 최근 적격 기간의 미공표 지표를 이전 기간 수치로 채우지 않습니다. 관찰한 시장 범위와 자료 공개시점은 입력자가 검증합니다.

관측 상태: `observed` = 적격 측정치; `estimate` = 조사기관 추정·잠정수치; `proxy` = 다른 지표·커버리지; `outlook` = 전망·계획. 별도 참고자료는 `metric: "context"`에 값 없이 기록합니다. `source`는 공시 URL이나 원출처의 문서 ID를 권장합니다. 예제의 수치는 가상이며 공급사 데이터 이용권이나 실시간 수집 연결이 아닙니다.

## 4단계 스크린에 연결하기

기존 입력에 `industry_observations`(위 행 형식)와 선택적 `industry_scopes`를 추가하고 각 `universe` 후보에 `sector_profile`을 명시합니다. 예: `{"symbol":"000660","sector":"semiconductor","sector_profile":"hbm"}`. HBM 판정 때문에 낸드가 통과하는 일은 없습니다. 프로필 모드에서 매크로가 먼저 막히면 종목 게이트는 건너뛰되, **시장 파악용** 업황표 전체는 `industry_report`에 남깁니다. 업황이 통과하지 않으면 차트·기업 평가도 넘기지 않습니다. 출력 스키마 3이며 기존 비프로필 가상 예제와 1차 글로벌 매크로 출력은 유지합니다.
