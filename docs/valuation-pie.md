# 주가 내재 기대(PIE)와 할인율 민감도

2026-11-25 리서치 기록. 주가에서 장기 영업이익을 역산하거나, 이익 경로를 주고 주당 가치를 계산한다. 역사적 기업 사례를 재현한 **가정 기반 계산**이며, 목표주가·매매 신호·가격 하한 또는 백테스트 실적이 아니다.

## 계산 순서

1. **입력과 시점을 고정한다.** 분석 시점, 주가와 거래 세션, 순현금 공시일, 발행·자기주식 수, 전망 작성일을 기록한다. 관측 주가와 전망에는 각각 최초 확인 가능 시각을 붙인다. 이하 사례의 할인 기준점은 2026-09-30이고 11월 전망을 사용하는 스냅샷이므로, 9월 시점의 백테스트 입력으로 쓰면 미래 정보가 섞인다.
2. **정상화 전 현금흐름을 추정한다.** 이 사례에서 `FCF 근사 = EBIT × (1 - 세율) - 재투자율 × 매출 증분`. 실제 FCF는 아니다. 분기 증분에는 직전 분기 대비 매출 차, 연간 증분에는 전년 대비 매출 차를 사용했다. 다음 적용 시 기간을 확인하고 실제 CAPEX·감가상각·운전자본 정보가 있으면 현금흐름을 직접 추정한다. 매출 감소만으로 대규모 현금 유입을 자동 가정하지 않는다.
3. **현재가치로 바꾼다.** `PV = FCF / (1 + r)^t`. 장기 가치에는 `TV = 장기 첫해 FCF / (r - g)`를 사용하며 `r > g`여야 한다. 아래 사례는 `g = 0`이고 장기 FCF를 `EBIT × (1 - 세율)`로 근사했다. 순재투자가 0이라는 단순화이지 유지 CAPEX가 없다는 뜻이 아니다.
4. **주가와 장기 이익을 양방향으로 계산한다.** `B = 순현금 + 명시기간 FCF의 PV 합`. `K = (1 - 세율) / r / (1 + r)^T`. `주주가치 = B + K × 장기 EBIT`. 여기서 `T`는 첫 장기 현금흐름 지급 1년 전까지의 기간으로 사례에서는 1.25년이다. `주당 가치 = 주주가치(원) / 주식 수`, `내재 장기 EBIT = (관측 주가 × 주식 수 - B) / K`이며 단위를 먼저 통일한다. 분기 환산은 연간 수치를 4로 나눈 **평균**이며 실제 분기별 경로가 아니다.
5. **저점 지속과 회복을 분리한다.** 2028년부터 `n`년간 낮은 이익 `L`을 내고, 이후 `H`로 회복해 그 수준이 유지되면, `장기 EBIT 환산 = L + (H - L) / (1 + r)^n`. 계속 저점이면 `H = L`. 낮은 기간의 현금흐름과 회복 후 영구가치를 각각 할인해도 같은 값이다.

### 할인율 적용 원칙

- 출발점은 자기자본비용 참고식 `r_e = 무위험금리 + 주식 베타 × 주식 위험프리미엄`. 반드시 같은 통화의 무위험금리와 측정일을 적고, 베타의 벤치마크·추정 구간, 위험프리미엄 출처를 같이 남긴다. 국채 수익률이나 기준금리를 그대로 주식 할인율로 쓰지 않는다.
- **10.08%**는 [삼성전자 PIE 영상](https://www.youtube.com/watch?v=LJVixaiOTN8&t=239s)에서 제시한 값을 재현 비교에 사용한 것이며, 하이닉스 고유 할인율로 추정한 값이 아니다. **12.3%**는 [키움 하이닉스 리포트](https://bbn.kiwoom.com/rfCI5748) p.37의 자기자본비용을 민감도에 차용한 값이다. 키움의 잔여이익 모형이나 목표가를 재현한 계산은 아니다.
- 이 사례는 영상과의 비교를 위해 세후 영업이익 기반 FCF 근사에 자기자본비용을 대입한 단순 모형이다. 정식 DCF에서는 **FCFF는 WACC로 할인해 기업가치에서 순차입금을 차감**, **FCFE는 자기자본비용으로 할인해 주주가치를 직접 계산**한다. FCFE에 이미 반영된 현금·부채를 다시 더하거나 빼지 않는다. 동일 위험을 이익 삭감과 할인율 할증에 중복 반영하지 않도록 단독 충격과 복합 충격을 표시한다.

### 최소 재현 코드 (Python 3.10+, 외부 패키지 없이 실행)

```python
SHARES = 706_799_093
KRW_PER_TRILLION = 10**12
TAX = 0.212
REINVESTMENT = 0.36

def base_and_multiplier(rate, ebit_2027, haircut=0.0):
    if rate <= 0:
        raise ValueError("The discount rate must exceed zero-growth g.")
    fcf_q4 = 101.826 * (1 - TAX) - REINVESTMENT * 26.045
    fcf_2027 = ebit_2027 * (1 - TAX) - REINVESTMENT * 130.079 - haircut
    base = 98.66 + fcf_q4 / (1 + rate)**0.25 + fcf_2027 / (1 + rate)**1.25
    multiplier = (1 - TAX) / rate / (1 + rate)**1.25
    return base, multiplier

def price_krw(rate, ebit_2027, trough, recovery=None, years=0, haircut=0.0):
    base, multiplier = base_and_multiplier(rate, ebit_2027, haircut)
    normalized = trough if recovery is None else trough + (recovery - trough) / (1 + rate)**years
    return (base + multiplier * normalized) * KRW_PER_TRILLION / SHARES

def implied_annual_ebit(price, rate, ebit_2027):
    base, multiplier = base_and_multiplier(rate, ebit_2027)
    return (price * SHARES / KRW_PER_TRILLION - base) / multiplier

assert round(price_krw(0.1008, 313.703, 34.639) / 10_000, 1) == 82.9
assert round(price_krw(0.123, 313.703, 34.639) / 10_000, 1) == 75.4
assert round(price_krw(0.123, 313.703, 34.639, haircut=50) / 10_000, 1) == 69.3
assert round(implied_annual_ebit(1_030_000, 0.1008, 383.239), 1) == 48.2
```
