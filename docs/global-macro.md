# 1차: 글로벌 매크로 관찰판

반도체 가격·주문·업종 상대수익률은 여기에 넣지 않습니다. 아래 40개와 보조 7개는 **시장 맥락 확인용**이며, 기존 환율·미 국채 10년물·HY OAS의 세 경계값에 추가 점수를 매기지 않습니다.

| 묶음 | 관찰 대상 |
|---|---|
| 국채 10 | 미국 2년·10년, 한국·일본·독일·영국·중국·호주·캐나다·이탈리아 10년 |
| 주요 환율 10 | USD/KRW·JPY·TWD·CNH·IDR, EUR/USD, GBP/USD, AUD/USD, USD/CAD, USD/CHF |
| 원자재 10 | WTI, 브렌트, 헨리허브 가스, 금, 은, COMEX 구리, LME 알루미늄 월물, SGX 철광석 62%, 시카고 밀, 옥수수 |
| 현물 주가지수 10 | S&P500, 나스닥100, 유로스톡스50, DAX 성과지수, FTSE100, 닛케이225, 코스피, 대만 가권, 홍콩 항셍, 상하이종합 |
| 개장 전 확인 5 | ES, NQ, 유렉스 FESX, 오사카 닛케이225, 대만 TX |
| 위험 교차 확인 2 | VIX, 미국 HY OAS |

- **금리:** 국채 수익률 레벨은 %, 변화는 bp. 미국 2년·10년 금리를 독립 투표로 세지 않습니다. 필요하면 두 만기의 차이로 방향을 해석하되 비교일이 같아야 합니다.
- **환율:** 기준시점은 출처별 고시·현물 마감을 고정합니다. 유로·파운드·호주달러처럼 달러가 분자인 호가는 표시값을 유지하되 변화율의 부호는 **양수 = 달러 강세**로 통일합니다. EUR 교차 고시는 같은 시각과 출처의 EUR/USD를 사용해야 합니다. CNH는 역외 위안으로 CNY와 대체 불가입니다.
- **원자재:** 현물과 선물을 구분합니다. 월물이 바뀌면 같은 월물의 이전 값을 확보하기 전까지 변화율을 내지 않습니다. 밀·옥수수는 센트/부셸입니다. 같은 원유의 WTI·브렌트나 비슷한 금속을 독립 근거로 중복 해석하지 않습니다.
- **지수·선물:** 현지 정규 현물 종가 및 현지 달력으로 비교합니다. DAX는 성과지수라 장기 가격수익률 비교 시 배당 포함 여부에 주의합니다. 미국 현물 휴장에는 직전 현물 종가의 날짜를 유지합니다. 주가지수 선물은 별도이며 같은 월물·출처·시각대의 스냅샷(UTC 시·분 일치) 또는 정산가끼리만 비교합니다. 선물과 대응 현물은 같은 `cluster`에 놓고 중복 투표를 하지 않습니다.
- **해석:** 40개가 동시에 움직였다고 단정하지 않습니다. 금리·달러·원자재·현물지수의 관측 시각을 먼저 보고, 주가 하락이 신용에 번졌는지(VIX·HY), 원자재 움직임이 에너지 공급 충격인지 경기 민감 금속까지 함께인지 구분합니다. 종목 수가 많다고 신뢰도가 자동으로 올라가는 구조가 아닙니다.

## 실행

```sh
python -m research.global_macro --input examples/global-macro.json
python -m research.staged --input examples/staged-research.json
python -m unittest discover -s tests -v
```

독립 CLI에는 `cutoff`와 `observations` 배열, 4단계 결과에 붙이려면 기존 단계형 입력에 선택적 `global_macro` 배열(같은 행 형식)을 추가합니다. 가상 예제에는 일부만 채웠고 나머지는 `missing_pair`로 나옵니다. 실시간 데이터 연결은 포함하지 않습니다.

각 관측 행은 `key`, `market_date`(해당 시장 거래일), `observed_at`, `available_at`(둘 다 시간대 포함), `basis`, `unit`, `value`, `source`, 월물에 한해 `contract`(YYYY-MM)를 기록합니다. 종목 코드·기준·단위·출처 후보는 [코드의 CATALOG](../research/global_macro.py)를 참고하세요. `source`는 같은 벤치마크·출처·마감 정의를 식별하는 고정 ID를 사용합니다. 날짜별로 달라지는 문서 URL은 입력 준비 단계에서 별도로 관리합니다. 출처 링크는 수집 경로 후보이지 특정 날짜 관측이나 데이터 사용권을 보증하지 않습니다. 비교 과정에서 아직 미공개였던 값은 제외하고 서로 다른 거래일의 관측만 비교합니다. 직전 관측이 직전 거래일인지 입력자가 거래소 달력으로 검증합니다. 7일을 넘는 비교는 보류하며, 공표 지연·원천 차이·만기 변경·결측을 0%로 대체하지 않습니다.
