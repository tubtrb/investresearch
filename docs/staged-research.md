# 4단계 주식 리서치 · v0.1.0 초안

```sh
python -m research.staged --input examples/staged-research.json
python -m unittest discover -s tests -v
```

예제는 가상 데이터입니다. `review`는 네 단계를 통과한 **검토 후보**이지 실제 주문이나 수익률 주장이 아닙니다. 기존 저점 이벤트 연구(`research.backtest`)는 그대로 유지합니다.

| 차수 | 역할 | 초기 판정 규칙 |
|---|---|---|
| 1. 매크로 | 시장 공통 신규 위험 예산 | 달러 대비 현지통화 약세 +0.5% 이상, 미국 HY OAS +10bp 이상, 미국 10년 만기 국채금리 +10bp 이상를 각각 경계로 잡습니다. 0~1개 경계는 기본, 2개는 절반, 3개는 보류. 하나라도 미확인이라면 비중 산정 없이 보류합니다. |
| 2. 업황·섹터 | 실수요와 가격이 함께 좋아지는 분야만 통과 | 같은 제품의 주문량과 계약가격 증가율이 모두 양수면 통과, 모두 음수면 탈락, 혼조·보합이면 보류합니다. HBM·서버 DRAM·기업용 SSD 등은 별도 키로 관리하고 현물가로 계약가를 대체하지 않습니다. 반도체 등 업종 상대수익률은 가격 반응을 보여주는 선택적 참고값이며 통과 여부에는 영향이 없습니다. |
| 3. 차트 | 후보 추리기, 매수 확정 아님 | 정규장 종가 기준 SMA5 > SMA10 > SMA20 및 종가 > SMA20, 직전 거래일에는 이 결합 조건 미충족. 전일 비교를 위해 연속 21거래일이 필요합니다. 이미 조건이 유지 중인 종목은 이 초기 신규진입 규칙에서 재신호로 보지 않습니다. |
| 4. 기업 | 재무와 밸류로 최종 거르기 | 최근 12개월 영업이익이 양수이고 전년 동기보다 증가, FCF(영업현금흐름 − 현금 CAPEX) 양수, EPS 양수 및 후행 PER이 사전 기록한 종목별 상한 이내면 통과합니다. 컨콜·제품별 마진·선행 EPS/PER은 별도 리서치 항목이며 이 기본 판정에서 추정하지 않습니다. |

예시의 최대 검토 비중은 코어 50% × 매크로 배수(1 또는 0.5)입니다. **단일 후보 예시**로, 여러 후보의 비중을 합산하는 자산배분 모델이 아닙니다. 마감 후 검토 시점에서 차트가 유지되어야 한다는 뜻이지 해당 종가에 소급 체결할 수 있다는 뜻이 아닙니다. 실제 주문, 포지션 관리, 추매·매도 신호, 달러 ETF 평가, 자동 알림은 포함하지 않습니다. 문턱값은 검증 전 고정 가설입니다.

## 입력 계약

UTF-8 JSON 하나를 입력합니다. 한 파일은 거래소 하나와 해당 정규장 종가 달력을 사용합니다. 한국과 미국의 세션을 섞지 말고 별도 실행합니다.

- `market`, `cutoff`, `regular_closes`: 시장 키, 판단 시각, 정렬된 거래소 종가 시각의 배열. 값이 없는 거래일도 달력에 두고 가격만 누락시킵니다. 모든 시각에 시간대(예: `+09:00`)를 넣습니다. KRX/NXT 및 장중/정규장 구분과 일관된 기업행사 가격 보정은 입력 제공자 책임입니다.
- `universe`: 종목별 `symbol`과 가장 중요한 단일 업황 키 `sector`. 해당 시점에 알던 제품 노출도를 입력합니다.
- `bars`: `symbol`, `close_at`, `available_at`, `session="regular"`, `close`, `source`. 컷오프에 아직 사용 불가였던 봉은 누락으로 봅니다. 같은 종목·일자에 하나의 정규장 종가만 받습니다.
- `evidence`: `kind`, `key`, `period_end`, `available_at`, `source`, `values`. 출처로 공시나 공급업체 자료의 URL·문서 ID를 기록할 수 있습니다. 정책 기준 날짜, 수정본의 첫 공개 시각과 원래 수치의 대상 기간을 분리합니다. 동일 관측 기간의 수정은 공개 시각 이후만 반영되며, 이미 더 최근 관측 기간이 있으면 과거 수정이 그 기간을 덮지 않습니다.

| 증거 종류 | 키 | 수치 |
|---|---|---|
| fx | market | `usd_local_change_pct`: 현지통화/달러(예: 원/달러)의 비교 가능한 두 마감 간 변화율, 양수는 현지통화 약세 |
| credit | market | `hy_oas_change_bp`: 미국 HY OAS의 최근 비교 가능한 일 변화(bp), 미국 국채 금리와 다름 |
| rates | market | `us_10y_change_bp`: 미 재무부 10년물 CMT의 연속 공개 영업일 변화(bp), 장중 호가와 혼용하지 않음 |
| breadth (선택) | sector | `sector_vs_benchmark_pct`: 같은 거래소·같은 기간 업종 지수와 벤치마크의 수익률 차(%p), 실제 참여 종목 비율은 아님 |
| orders | sector | `orders_change_pct`: 같은 정의·같은 제품의 비교 기간 대비 확인된 주문량 변화율(%) |
| contract_price | sector | `price_change_pct`: 같은 정의·같은 제품의 비교 기간 대비 계약가 변화율(%) |
| financials | symbol | `op_income`, `op_income_prior`, `cfo`, `capex`, `eps`: 최근 12개월 공시 기준 전년 비교 영업이익과 현금흐름. CAPEX는 양수 지출, EPS와 주가는 동일 통화·주식 수 단위 |
| valuation | symbol | `max_trailing_pe`: 해당 판단 전에 확정한 후행 PER 상한, 산정 근거를 출처에 기록 |

입력 스키마 변경: 이전 1차 입력에는 `rates` 관측을 추가해야 합니다. 없으면 `unknown`이며 `breadth`를 대체로 쓰지 않습니다. 출력의 `schema_version`은 2입니다. +10bp는 사전 검증용 초기값이고 기존 10년물 금리 수준 경보와 별개입니다.

증거별 최대 유효 일수는 코드와 JSON 결과에 공개합니다. 서로 다른 시장의 휴장·공표 지연을 허용하되 가능한 한 경제적 관측 기간을 맞춰 입력합니다. 예컨대 새 기업 공시나 컨콜이 오늘 공개되었다고 몇 달 전 주문이 오늘 발생한 것으로 기록하지 않습니다.

## 출력과 검증 범위

종목별 네 단계 상태, 첫 차단 단계, 사용한 근거와 시각을 JSON에 기록합니다. `unknown`은 자료 부족·지연, `hold`는 조건 미성립·혼조, `fail`은 확인된 탈락, `skipped`는 앞 단계에서 중단입니다. 이 CLI는 데이터를 내려받거나 출처의 사실성을 판정하지 않으며 데이터베이스에 쓰지 않습니다. 실데이터 비교 시 동일한 종목 유니버스·시점·가격으로 차트 단독을 기준군으로 만들고, 필터가 제거한 손실과 놓친 반등을 비교합니다. 공개 이전 수치, 사후 선정 표본, 목푯값 튜닝을 검증 구간에 되돌려 넣지 않습니다.
