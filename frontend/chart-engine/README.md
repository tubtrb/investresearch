# InvestResearch 독립 차트 엔진 v0.1.0

네이버 화면과 데이터에 의존하지 않는 차트 프런트엔드. 가격 데이터와 표시 엔진을 분리했다. 기본 예제는 가상 데이터이고 실제 체결가가 아니다. 호가 조회, 매매, 네이버 데이터 수집 또는 기존 전략 자동화 변경은 하지 않는다.

```sh
cd frontend/chart-engine
npm ci
npm test
npm start
# http://127.0.0.1:4173
node build-offline.mjs
# dist/InvestResearch-chart-engine-v0.1.0.html: Chrome/Edge에서 로컬로 열기
```

## 기능·범위

| 항목 | v0.1.0 |
|---|---|

| 주기 | 1/5/15/30/60분, 일·주·월, 전체/최근 100봉/연초 이후 |
| 기술 지표 | 이동평균 최대 6개, 볼린저 20±2σ, 일목 9/26/52/26, 거래량, RSI, MACD, KDJ, ATR, OBV 및 추가 내장지표 |

| 비교 | 최대 4개 종목 또는 시장을 같은 주기와 별도 가격축으로 비교. 자동 축·십자선 동기화는 미구현 |
| 그리기·저장 | 수평·수직·추세·반직·평행·피보나치·가격 라벨과 차트 PNG. 그림은 현재 뷰에서만 유지되며 PNG에 별도 매물대·다른 종목 패널은 포함되지 않음 |
| 보강 예정 | 허가된 시세 서비스 연동, KRX/NXT 호가·체결 및 수정주가 검증, 로그인·관심종목, 재생·저장·동기화, 실거래 캘린더와 중단 구간 검증, 매물대 가격축 오버레이, 일반/반등/최악 시나리오 |
 
모든 네이버 기능과의 일치나 동일한 수치 계산 및 사이트의 계정·주문 기능을 보장하지 않는다. 일목 구름은 입력 이력에 해당하는 범위만 그린다. 거래소별 시간대를 적용하지만 CSV의 세션·완전성은 공급자 책임이다. 일봉을 분봉으로 생성하지 않는다. 일봉 입력이 있으면 일·주·월에는 일봉이 우선한다. 거래량이 없는 지수에는 매물대를 그리지 않는다. 연초 이후는 입력 최신 바의 현지 연도다.

## CSV

UTF-8, 콤마 구분, 필드 내부 콤마·줄바꿈 미지원. UTC 또는 시간대 오프셋이 포함된 ISO 날짜. 각 종목·거래소에 한 통화 사용. 정규장/프리/애프터 시세는 반드시 별도 세션으로 라벨링. 분봉은 한 분의 시작 시각, 일봉은 거래소 현지 날짜의 적절한 시각. 수정/비수정주가는 동일한 파일·시계열에서 섞지 않는다.

```csv
symbol,timestamp,open,high,low,close,volume,market,session,resolution,name,currency
263750,2026-11-25T15:30+09:00,40000,42100,39000,41200,20000,KRX,regular,D,펄어비스 가상,KRW
263750,2026-11-25T09:00+09:00,40000,40200,39900,40050,120,KRX,regular,1m,펄어비스 가상,KRW
```

시장: KRX, NXT, US, JP. 세션: regular, pre, post. 해상도: D, 1m. 일봉에는 regular만 사용. 지수 등 없는 거래량은 빈칸. CSV는 브라우저 안에서만 읽으며 업로드하지 않는다.

## 공개 저장소 비교

- [KLineChart](https://github.com/klinecharts/KLineChart), Apache-2.0. 이동평균/거래량/RSI/MACD와 그리기 기본 제공, 모바일 대응. 현재 엔진은 9.8.12로 고정하고 계산·입력·거래소 분리·일목·매물대는 우리 코드가 담당.
- [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts), Apache-2.0 및 프로젝트의 표시·NOTICE 조건 확인 필요. 가벼운 금융 렌더링과 확장 플러그인. 이 요구의 도구와 지표를 다시 조립해야 해 첫 버전에서는 채택하지 않음.
- [Apache ECharts](https://github.com/apache/echarts), Apache-2.0. 캔들과 줌도 있지만 주력 장점은 범용 시각화. 수급·자금흐름 등 별도의 대시보드 후보.
- [KLineChart extension](https://github.com/klinecharts/extension), Apache-2.0. 드로잉 도구 확장 후보. 채택 전 현재 고정 버전과 호환성을 검증해야 함.

오프라인 HTML에 포함되는 KLineChart 라이선스는 패키지의 LICENSE/NOTICE 및 배포본 헤더를 따른다. 브랜치만 작업하고 기존 main 및 시장 점검과 분리한다.
